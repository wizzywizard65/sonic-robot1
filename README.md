# Sonic-Robot Bootc image

This image is based on Fedora Silverblue. I used a Universal blue template to produce my own custom Bootc image.Look at the build_files/build.sh file to see what is installed. (subject to change)


# How to Use

Install Fedora Silverblue then just switch to it with the command: bootc switch https://github.com/wizzywizard65/sonic-robot1
